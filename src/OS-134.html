I/O 控制方式

B级 · OS-134

1直觉引入

CPU 怎么指挥设备干活？四种方式的演进，主线就一条：让 CPU 干预越来越少、设备与 CPU 并行度越来越高。

① 程序直接控制（轮询）：CPU 反复查状态寄存器，忙等，利用率极低；② 中断驱动：CPU 发完命令就去干别的，设备就绪才发中断来「叫人」，但每传一个字（节）就打一次；③ DMA：数据搬运整个交给 DMA 控制器，直接进出内存，整块传完才中断一次；④ I/O 通道：通道本身是一台小处理器，执行「通道程序」批量指挥设备，CPU 几乎零干预。
