# 408 计算机学科专业基础综合考试大纲

> 满分 150 分，考试时长 180 分钟。
> 数据结构 45 分 + 计算机组成原理 45 分 + 操作系统 35 分 + 计算机网络 25 分。
> 单项选择题 40 题 × 2 分 = 80 分；综合应用题 70 分（算法设计、原理分析、计算推导）。

## 第一部分 数据结构（45 分）

### 一、基本概念
- 数据结构的基本概念
- 算法的基本概念
- 时间复杂度和空间复杂度分析

### 二、线性表
- 线性表的基本概念
- 线性表的实现
  - 顺序存储（顺序表）
  - 链式存储（链表）
- 线性表的应用

### 三、栈、队列和数组
- 栈和队列的基本概念
- 栈和队列的顺序存储结构
- 栈和队列的链式存储结构
- 多维数组的存储
- 特殊矩阵的压缩存储
- 栈、队列和数组的应用
- 串（串的模式匹配、KMP 算法）

### 四、树与二叉树
- 树的基本概念
- 二叉树
  - 二叉树的定义及其主要特征
  - 二叉树的顺序存储结构和链式存储结构
  - 二叉树的遍历
  - 线索二叉树
  - 哈夫曼树与哈夫曼编码
- 树、森林
  - 树的存储结构
  - 树与二叉树的转换
  - 森林与二叉树的转换
  - 树和森林的遍历
- 树与二叉树的应用
  - 二叉排序树（BST）
  - 平衡二叉树（AVL）
  - 红黑树
  - 并查集

### 五、图
- 图的基本概念
- 图的存储结构（邻接矩阵、邻接表）
- 图的遍历（DFS、BFS）
- 图的应用
  - 最小生成树（Prim、Kruskal）
  - 最短路径（Dijkstra、Floyd）
  - 拓扑排序
  - 关键路径（AOE 网）

### 六、查找
- 顺序查找
- 折半查找（二分查找）
- 分块查找
- 二叉排序树查找
- 平衡二叉树查找
- B 树与 B+ 树
- 散列表（哈希表）及其冲突处理
- KMP 算法

### 七、排序
- 插入排序（直接插入、折半插入、希尔排序）
- 交换排序（冒泡排序、快速排序）
- 选择排序（简单选择排序、堆排序）
- 归并排序
- 基数排序
- 各种内部排序算法的比较
- 外部排序

## 第二部分 计算机组成原理（45 分）

### 一、计算机系统概述
- 计算机发展历程
- 计算机系统层次结构
- 计算机的基本组成
- 计算机的性能指标

### 二、数据的表示和运算
- 数制与编码
- 定点数的表示和运算
- 浮点数的表示和运算
- 算术逻辑单元（ALU）

### 三、存储系统
- 存储器的分类与层次结构
- 主存储器（SRAM、DRAM、ROM）
- 高速缓冲存储器（Cache）
- 虚拟存储器
- 存储器的校验

### 四、指令系统
- 指令格式
- 指令的寻址方式
- CISC 与 RISC
- 机器级代码的表示

### 五、中央处理器（CPU）
- CPU 的功能和基本结构
- 指令执行过程（指令周期）
- 数据通路
- 控制器的功能和工作原理
- 指令流水线
- 中断系统

### 六、总线
- 总线概述
- 总线的分类与结构
- 总线仲裁与控制
- 总线性能指标

### 七、输入/输出系统
- I/O 系统的基本概念
- 外部设备
- I/O 接口
- I/O 控制方式（程序查询、程序中断、DMA、通道）
- 中断系统

## 第三部分 操作系统（35 分）

### 一、计算机系统概述
- 操作系统的基本概念
- 操作系统的发展历程
- 操作系统的运行环境
- 操作系统的体系结构
- 虚拟机

### 二、进程与线程
- 进程与线程
  - 进程的概念、组成、特征
  - 进程的状态与转换
  - 进程控制
  - 进程通信
  - 线程的概念与多线程模型
- CPU 调度
  - 调度的基本概念
  - 调度算法（FCFS、SJF、RR、优先级、多级反馈队列）
- 同步与互斥
  - 进程同步与互斥的基本概念
  - 信号量机制（PV 操作）
  - 经典同步问题（生产者-消费者、读者-写者、哲学家进餐）
- 死锁
  - 死锁的概念与必要条件
  - 死锁预防
  - 死锁避免（银行家算法）
  - 死锁检测与解除

### 三、内存管理
- 内存管理概念
  - 内存管理的功能
  - 程序装入与链接
  - 连续分配管理方式
  - 非连续分配管理方式（分页、分段、段页式）
- 虚拟内存管理
  - 虚拟内存的基本概念
  - 请求分页管理方式
  - 页面置换算法（OPT、FIFO、LRU、CLOCK）
  - 抖动与工作集

### 四、文件管理
- 文件系统基础
  - 文件的概念与属性
  - 文件的逻辑结构
  - 文件的物理结构
- 目录
  - 目录的基本概念
  - 目录结构
  - 目录操作
- 文件系统
  - 文件系统的全局结构
  - 文件存储空间的管理
  - 文件共享与保护

### 五、输入/输出管理
- I/O 管理概述
- I/O 控制方式
- 设备独立性软件
- 缓冲管理
- 磁盘和固态硬盘（磁盘调度算法）

## 第四部分 计算机网络（25 分）

### 一、计算机网络体系结构
- 计算机网络概述
  - 计算机网络的概念、组成与功能
  - 计算机网络的分类
  - 计算机网络的性能指标
- 计算机网络体系结构与参考模型
  - 分层结构、协议、接口、服务
  - OSI 参考模型
  - TCP/IP 模型

### 二、物理层
- 通信基础
  - 基本概念（数据、信号、信道）
  - 信道的极限容量（奈奎斯特定理、香农定理）
  - 编码与调制
- 传输介质
- 物理层设备（中继器、集线器）

### 三、数据链路层
- 数据链路层的功能
- 组帧
- 差错控制（检错编码、纠错编码）
- 流量控制与可靠传输机制
  - 停止-等待协议
  - 后退 N 帧协议（GBN）
  - 选择重传协议（SR）
- 介质访问控制
  - 信道划分（FDM、TDM、WDM、CDMA）
  - 随机访问（ALOHA、CSMA、CSMA/CD、CSMA/CA）
  - 轮询访问（令牌传递）
- 局域网（以太网、IEEE 802.3）
- 广域网
- 数据链路层设备（网桥、交换机）

### 四、网络层
- 网络层的功能
- 路由算法（静态路由、动态路由、距离向量、链路状态）
- IPv4（地址、子网划分、CIDR、ARP、DHCP、ICMP）
- IPv6
- 路由协议（RIP、OSPF、BGP）
- IP 组播
- 移动 IP
- 网络层设备（路由器）

### 五、传输层
- 传输层提供的服务
- UDP 协议
- TCP 协议
  - TCP 的特点
  - TCP 连接管理（三次握手、四次挥手）
  - TCP 可靠传输
  - TCP 流量控制
  - TCP 拥塞控制

### 六、应用层
- 网络应用模型（C/S、P2P）
- DNS 域名系统
- FTP 文件传输协议
- 电子邮件（SMTP、POP3、IMAP）
- 万维网（WWW、HTTP、HTTPS）
